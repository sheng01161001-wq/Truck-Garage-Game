卡車改裝王｜橫向電影模式：替換成自己畫的精緻 PNG

把 PNG 檔放在這個資料夾（assets/side/），檔名照下面，重新整理網頁就會自動換上；沒放的部分繼續用程式畫的。
建議用「透明背景 PNG」，解析度可以畫成下面尺寸的 2～3 倍，比較清楚。

卡車座標：寬 740、高 320（x＝0 是拖車尾巴，往右是車頭；y＝300 是地面）
檔名            放的位置（左上角 x, y）  大小（寬 × 高）  說明
chassis.png     10, 220                 700 × 50         底層車架、懸吊（會跟著避震器上下彈）
trailer.png     14, 60                  512 × 182        拖車車身（含塗裝、文字）
cab.png         540, 60                 175 × 196        車頭（含車窗、水箱罩）
bumper.png      676, 214                40 × 46          保險桿（有放就一直顯示）
spoiler.png     548, 40                 140 × 52         車頂導流罩（改裝有選才顯示）
lightbar.png    560, 46                 130 × 18         車頂 LED 燈條（改裝有選才顯示）
stacks.png      534, 20                 22 × 228         直立排氣管（改裝有選才顯示）
wheel.png       （每顆輪子）             64 × 64（正方形） 輪子，會自動旋轉，中心＝輪軸

小提醒：
- cab.png、trailer.png 放了以後，車身顏色就以你畫的為準（車庫裡換顏色不會改到圖）。
- 頭燈光束、煞車燈光暈、陰影、廢氣、天氣都還是程式畫的，會疊在你的圖上面。

==================== 角色序列幀（Sprite Sheet） ====================
放在 assets/side/sheets/，一組 = 一張 PNG（一格一格排好，由左到右、由上到下）＋同名 JSON（可省略）。
目前會用到的名字：
  walker.png / walker.json   人行道上的行人（動作：walk 走路、idle 站著、umbrella 撐傘走路）
  driver.png / driver.json   駕駛座裡的司機（動作：idle）

JSON 範例（walker.json）：
{ "frameW": 64, "frameH": 128, "fps": 10,
  "anims": { "walk": { "from": 0, "to": 7 }, "idle": { "from": 8, "to": 11 }, "umbrella": { "from": 12, "to": 19 } } }
- frameW／frameH：每一格多寬多高（像素）
- from／to：這個動作用第幾格到第幾格（從 0 開始數）
- 沒放 JSON：當作每格是正方形、整張都是 walk

播放方式：相鄰兩格會淡入淡出（比較順），換動作時舊動作慢慢淡掉（動作混合）。
素材來源可以用 Midjourney、Leonardo.ai 生成去背圖，或 Kenney、itch.io 的免費素材（注意授權）。
沒放圖就用程式畫的人物。
