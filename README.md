# 🚛 卡車改裝王（寫實版 v29）

寫實風格的重型聯結車模擬遊戲（網頁版，電腦、平板、手機都能玩，不用安裝）。

**網址：** https://sheng01161001-wq.github.io/Truck-Garage-Game/

## 怎麼玩
- **開車**：↑ 油門、↓ 煞車（停住後按住 = 倒車）、← → 方向盤。平板手機用畫面上的按鈕。
- **送貨**：跟著小地圖的**橘色導航線**開，停進黃色「裝卸區」等 3 秒自動裝貨／卸貨。零碰撞送達有 25% 獎金。
- **加油**：開進加油站停好會自動加油；或在改裝廠加。
- **上山送貨**（v3）：市區東邊接國道 → **收費站**（減速到 30 以下柵欄才會開，過路費 15 金幣）→ 8% 陡坡山路 → **山風隧道** → 山上**林場**（空地可以迴轉）。上坡會變慢、下坡自動排氣煞車不超過 90。
- **改裝廠**（🔧）：車頭款式（歐式平頭／美式長鼻）、車斗（廂型貨櫃／平板／砂石斗）、烤漆、特殊漆、彩繪、零件、喇叭、底盤燈、拖車名字；還能洗車、修理、加油。

## v22 完整國道交流道
- **東門環狀交流道（國道入口）**：南北向的 x=400 改成 7 公尺高架橋，跨過往國道的路；四個角落各一條 270 度環道（苜蓿葉型），高架上的車可以繞下來上國道，地面的車也可以繞上高架。
- **多層立體交叉**：橋下的路口照樣可以轉彎；在橋上不能直接轉下去（有護欄），要走環道或匝道。地面的車會撞到橋墩，橋上的車不會。
- **出口選擇**：高架上、地面上都有出口預告牌（國道入口、上高架往北倉・南郊）。
- **導航會走多層道路**：GPS 知道哪裡是橋、哪裡是匝道，在高架上會帶你走環道下去；橋下的路口不會叫你在橋上轉彎（`js/roadnet.js`）。
- 所有高架（GPT 做的市區高架、東區高架、四條匝道，加上新的交流道）統一放在 `js/elevated.js`：路面高度、碰撞、導航、小地圖共用。
- 另外一起上線（另一個對話做的寫實素材）：路上的車換成真實車款模型、柏油／人行道／紅磚照片貼圖、白天天空反射、改裝廠道具。


## v23 真實 AI 交通
- **每個方向兩條車道**（市區和國道都是，路上有白色虛線）：車子會跟車（保持約 1.3 秒車距）、換車道、超車，超完回外側；要右轉先換到外側、左轉先換到內側。國道的大貨車走外側。
- **繞過障礙**：前面有拋錨車、或你的卡車停在車道上，後面的車會換車道繞過去，不會一直卡著。
- **事故**：每隔一陣子，市區某處會有車拋錨，閃故障燈、後面放三角架和三角錐，小地圖上出現紅色三角形；大約 75 秒後排除。你撞到別的車，那台車也會停下來閃故障燈。
- **紅綠燈**：市中心 16 個路口都有紅綠燈。前面紅燈會提醒，紅燈還開過去會跳「闖紅燈」。
- **車流密度**：🌤 面板可以選「車流：少／中／多」，選多的時候路口會塞車。


## v24 第一人稱駕駛座＋寫實光影
- **畫面後製**（畫質選「高」時）：環境光遮蔽（物體角落、接縫的自然陰影）、車燈路燈發光、4 倍抗鋸齒。電腦跑不動時會自動關掉最吃效能的那一項。
- **駕駛座**（按 📷 鏡頭切到「駕駛座」）：儀表板上是真正會動的轉速表、速度表，中控台有導航螢幕，方向盤會跟著轉，排檔桿、門板、遮陽板、車頂內襯。
- **數位後照鏡**：駕駛座視角時畫面左右上方各一個，看得到車後面和拖車（隔幾格更新一次，平板也不會太卡）。
- 駕駛座視角比較廣（看得到兩邊窗外），拖曳畫面可以左右轉頭看。


## v25 重型卡車物理
- **車斗不一樣**：廂型貨櫃最重、重心高；平板車輕、重心低（比較不會翻）；砂石斗最重。
- **載重**：越重煞車距離越長（從 50 公里煞停：空車約 16 公尺、滿載約 26 公尺、下雨滿載約 31 公尺），重心越高越容易翻；裝貨時會提醒。
- **輪胎抓地力**：太快轉太急會推頭打滑（下雨、碎石路更早），打滑的空車只會滑、不會翻；滿載又重心高才會翻。
- **折刀甩尾**：下雨時邊轉彎邊重踩煞車，拖車會往外甩。
- **排氣煞車**（新按鈕 🛑，鍵盤 J）：放開油門時幫忙減速，下坡控速很好用；煞車一直踩會越來越燙、越來越沒力，儀表會顯示煞車溫度。
