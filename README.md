# 🚛 卡車改裝王（寫實版 v2）

寫實風格的重型聯結車模擬遊戲（網頁版，電腦、平板、手機都能玩，不用安裝）。

**網址：** https://sheng01161001-wq.github.io/Truck-Garage-Game/

## 怎麼玩
- **開車**：↑ 油門、↓ 煞車（停住後按住 = 倒車）、← → 方向盤。平板手機用畫面上的按鈕。
- **送貨**：跟著小地圖的**橘色導航線**開，停進黃色「裝卸區」等 3 秒自動裝貨／卸貨。零碰撞送達有 25% 獎金。
- **加油**：開進加油站停好會自動加油；或在改裝廠加。
- **改裝廠**（🔧）：車頭款式（歐式平頭／美式長鼻）、車斗（廂型貨櫃／平板／砂石斗）、烤漆、特殊漆、彩繪、零件、喇叭、底盤燈、拖車名字；還能洗車、修理、加油。

## 按鍵
| 鍵 | 功能 | 鍵 | 功能 |
|---|---|---|---|
| Q / E | 左／右方向燈 | X | 警示燈 |
| L | 大燈 | K | 雨刷 |
| H | 喇叭 | C | 換鏡頭（追車、高空、駕駛座、路邊轉播） |
| T | 換時間（白天、黃昏、晚上） | Y | 換天氣（晴、雨、霧） |
| G | 改裝廠 | R | 回改裝廠門口 |

## 寫實化內容
- 卡車：圓角車身、雨刷、後照鏡、格柵、LED 日行燈、胎紋輪胎、油箱、氣壓管線、傳動軸、擋泥皮；會髒（要洗車）
- 物理：12 段自動排檔、轉速、載重影響加速與煞車、車身側傾與懸吊晃動、草地／砂石路比較難開
- 場景：遠方山脈、柏油路（胎痕、補丁、裂縫）、市區大樓、路燈、紅綠燈、車流、港口、工地、農場、加油站
- 天氣：白天、黃昏、晚上；晴天、下雨（積水、濕路面）、起霧
- 儀表：轉速表、速度表、檔位、油量、水溫、車損、方向燈
- 聲音：柴油引擎、渦輪、換檔、氣壓煞車、方向燈、胎噪、風切、雨聲

## 給爸爸媽媽
- 進度存在這台裝置的瀏覽器裡。
- **密技**：左上角金幣在 3 秒內連點 7 下，加 1000 金幣。
- 手機平板卡卡的話：🌤 天氣 → 畫質選「順」。
- 需要網路（3D 引擎從網路載入）。

## 檔案
- `index.html`、`style.css`、`game.js`（主程式）
- `js/`：`truck.js` 卡車模型、`world.js` 地圖、`env.js` 天空天氣、`traffic.js` 車流、`audio.js` 聲音、`hud.js` 儀表與導航、`textures.js` 貼圖、`util.js`
- 改版時把 `game.js` 裡的 `VERSION` 加一。
