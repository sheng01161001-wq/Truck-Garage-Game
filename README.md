# 🚚 卡車改裝王

給小朋友玩的大卡車遊戲（網頁版，電腦、平板、手機都能玩，不用安裝）。

**網址：** https://sheng01161001-wq.github.io/Truck-Garage-Game/

## 怎麼玩
- **開車**：方向鍵 ↑↓←→ 或 W A S D；平板／手機用畫面上的大按鈕（油門、煞車／倒車、左右）。
- **送貨**：跟著卡車頭上的**黃色箭頭**開，先去載貨，再送到目的地。開進發光的圈圈裡**停下來**就算完成，可以拿到金幣。
- **改裝**：按右上角 🔧 **車庫**：
  - 🎨 烤漆：車身顏色（免費）＋特殊漆（消光、金屬、珍珠變色、霓虹發光、電鍍鏡面、變色龍）
  - 🔥 彩繪：圓點、賽車條紋、格子、迷彩、星星、閃電、火焰、老虎紋、彩虹
  - 🔧 零件：鐵牛欄、電鍍保險桿、黃金／電鍍輪框、直立排氣管、車頂燈條、遮陽板、導流罩
  - 📯 喇叭燈：搞笑喇叭、火車喇叭、牛叫喇叭、各色底盤燈
  - 🚛 拖車：拖車顏色、彩繪、把自己的名字寫在拖車上
  - 點一下就能先試看，喜歡再按「買下來！」
- 其他按鈕：📯 喇叭（H）、💡 大燈（L）、📷 換鏡頭（C）、🔄 回車庫門口（R，卡住時用）、🔊 聲音開關。

## 給爸爸媽媽
- 進度（金幣、買過的零件）存在這台裝置的瀏覽器裡，換裝置要重新開始。
- **密技**：左上角金幣在 3 秒內連點 7 下，加 1000 金幣。
- 需要網路（3D 引擎從網路載入）。

## 檔案
- `index.html` 畫面、`style.css` 外觀、`game.js` 遊戲程式（Three.js 3D）。
- 改版時把 `game.js` 裡的 `VERSION` 加一。
